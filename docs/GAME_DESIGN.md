# 游戏设计

玩家在十个区域敲蛋、孵化并收集动物，携带动物回到牧场获得收益，通过镐、跑步机、拖尾及牧场升级推进成长。七名玩家共享地图，Room 负责权威玩法状态；个人资产与设置通过平台账户能力保存。

人物支持移动、跳跃、动画和第三人称旋转缩放镜头。地图保留区域守卫、基地设施与碰撞，基地初始不放置动物，不显示邀请人物。

蛋按区域配置生成，包含生命值、大小、稀有度、成长与奖励。守卫巡逻和追击使用预烘焙导航与有预算的追击规划。动物支持收藏、背包、放置、收益与合成；图鉴领奖包含现金和速度反馈。

商店、离线奖励与加速使用平台支付。付款前只检查资格，不持久化准备或冻结正常玩法；成功后保存订单回执并交付。离线收益双倍、指定单蛋加速和全部蛋加速固定为 100 G。

UI 适配横屏、安全区和触控，文字使用黑色描边。除已明确要求的功能反馈，不增加操作说明和调试统计。玩家只看见自己的牧场升级牌。声音服从平台静音、游戏音量及前后台状态。

地图、模型和布局以 `h5-map/public/` 中的运行资产为维护基础。清理可选元数据不改变玩法、视觉资产或存档协议。后续功能逐项安排，待办不视为已实现。
