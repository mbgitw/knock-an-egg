## 后续搬运接口

`window.game.guards` 为当前系统。正式模块接入时直接持有同一实例：



抓捕先提交状态、清除内部携带，再通知 `onDrop`/`onCaught`；回调异常不会撤销已提交抓捕。一个被抓携带 token 不再触发第二次抓捕；下一次 `setCarrying()` 生成新 token。不要把回调存入账户存档。

也可通过 `setTargetProvider(() => ({position, velocity, carrying, power, safe, disabled}))` 接入外部搬运状态。`position` 为脚底坐标；`carrying: null` 明确解除携带。外部提供器每次返回新对象时，须为同一搬运实例保持稳定的 `carrying.token`，交付新实例时更换 token。`setTargetProvider(null)` 恢复默认玩家/内部携带接口。接口只提供目标与事件，不替后续模块修改库存。
