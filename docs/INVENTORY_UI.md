## 数据与玩法边界

### 原提示机制核查（2026-10-24）



- 蛋入口统计带 `MergeConfig.PlacedEggTag` 标签、属于本地玩家且 `Ready=true` 的模型；数量>0显示绿色数字角标，0隐藏。新增/移除蛋、Ready/OwnerUserId变化会刷新。普通场景可敲蛋、背包里未放置的蛋、仍在成长的蛋均不计入。
- 数字增加或由隐藏变为显示时，原角标以0→1缩放、0.35秒Back.Out弹出；可见时提醒循环每轮先等待15秒，再产生两道扩圈，间隔0.45秒，各1.6秒、终点2倍。H5只有静态绿色数字及零隐藏，**未加入上述弹出/周期扩圈**。
- H5按只读 `growingEggs.readyAt <= Date.now()`推导成熟，与原服务端Ready属性不同；当前正式玩法没有写入成长蛋记录的流程，因此只能在隔离样例/传入数据时显示，不能称为成熟提醒已贯通。
- 原爪印入口没有Notification子节点，也未找到对应宠物角标控制器；新宠物或基地放满并不在这套源码中触发爪印角标。H5同样没有宠物角标。
- 原宠物面板扩容按钮通过AffordabilityFX随现金变为可购买/余额不足样式，满级变黄并显示MAX。H5只更新价格/MAX文字，按钮仍固定绿色且未绑定操作；**面板的余额/满级颜色反馈尚未加入**。地图围栏升级牌已有余额状态，不能算作这个面板的实现。
- NotificationConfig另有NoEggsGrowing、BaseFull/BaseFullUpgrade、PetsFull、EquipBestCooldown等文字消息；副本无服务端，不能仅凭预设文案断言精确调用条件。这些原通知流程当前未接入H5两个面板。

本次为源码核查，未新增提示或修改玩法。

本次是 UI 请求，不启动 T09/T10/T22 整套经营玩法。`Grow All`、加速、`Open`、`Unequip`、`Equip Best`、容量购买保留原视觉且标记 `aria-disabled`，没有扣款、放置、发奖或存档写入。围栏现有牌面升级仍由原系统处理。

`inventorySnapshot()` 只读取现有围栏等级，并预留 `account.data.plot.pets`（已放置宠物）与 `account.data.growingEggs`（毫秒 readyAt / 秒 duration）的只读显示适配。当前持有收藏 `pickaxes.pets` 不等于已放置宠物，不能拿它填基地列表；采集到的 PlacedAnimals 也不会回填。正式游戏当前没有这两类经营记录，面板为空是正确状态。后续玩法实现应对接权威实体、变体、收益公式和存档迁移，不把本轮只读字段当作已完成的保存协议。
