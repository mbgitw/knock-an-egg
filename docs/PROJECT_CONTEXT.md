当前为 H5 + Three.js 横屏牧场游戏，开发目录 `h5-map/`。项目保留运行资源、客户端、Room、测试和构建工具。历史资源工作目录与旧构建产物已清理，后续直接维护现有运行资产，不依赖历史导入流程。

入口为 `public/index.html` 和 `public/app.js`；玩法在 `public/gameplay/`，联机在 `public/online/`，Room 在 `server/game/`。地图为 `public/obj-map/world.glb`，碰撞和场景布局为 `public/map.json`。模型的加载路径、几何、骨骼、动画、材质和挂点保持有效。

移动、跳跃、人物动画、第三人称镜头、碰撞、敲蛋、孵化、动物收藏、牧场收益、装备与跑步机成长、商店、图鉴、设置和联机已接入。具体行为以当前代码和测试为准。
