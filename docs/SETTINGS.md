# 设置系统（T27，2026-10-25）

正式入口为 `http://localhost:8765/`，顶部背包旁的齿轮打开 Settings。沿用原 `/StarterGui/MainGUI/Frames/Settings` 的比例、滚动列表、顺序、英文文案、滑条和滑块；关闭按钮或 Esc 退出。打开时锁定移动、视角与挥击，并与现有面板互斥。没有增加调试、说明或保存提示面板。





| 原字段 | 默认 | 当前接入 |
| --- | --- | --- |
| MusicVolume | 1 | 三首原日常背景音乐的音量，0完全静音；用户交互后开始，后台/宿主暂停时暂停 |
| SfxVolume | 1 | 训练、购买、挥镐、敲蛋、孵化现有声音统一增益；已播放中的循环声音也立即响应 |
| ViewOthersPets | true | 独立保存，按宠物 ownerId 与当前基地身份选择可见性；正式主画面目前无其他玩家宠物 |
| ViewMyPets | true | 隐藏牧场宠物、其收益/爱心飘字与放置粒子，游走和收益继续 |
| ViewMyEggs | true | 隐藏自己已放置的成长蛋及场景倒计时/Open按钮；成长、列表孵化和刷新恢复继续；不隐藏地图可敲蛋、手持蛋或背包 |
| ScreenFFX | true | 当前H5的入库全屏闪光/FOV反馈开关；关闭时清除正在进行的闪光并恢复FOV，获得卡保留 |



设置存入现有账户 `settings` 字段，不新增存档键；旧档默认全开/音量100%，类型校验与数值钳制，0和false保留。连续操作每0.5秒合并保存，拖动结束、关闭、切后台和离页立即flush；存储失败保持当前值并重试，不回滚其他玩法字段。当前仍为浏览器本地账户，未实现原 SettingsRemote 的服务器持久化或跨设备云存档。
